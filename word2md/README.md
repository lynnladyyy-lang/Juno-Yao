# Word 转 Markdown 脚本（word2md）

把 Word 文档（`.doc` / `.docx` / `.rtf`）稳定转换为 Markdown，保留标题、粗体/斜体、列表、表格，并自动导出文档中的图片。

## 这是什么

一个本地 Word 转 Markdown 工具。**双击启动器会自动打开一个网页**：页面右侧选择 Word 文件、点击下方「开始转换」，左侧即可看到每个文件的转换结果。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `word2md.bat` | 双击启动本地服务并自动打开网页 |
| `word2md_server.py` | 本地 Web 后端（接收文件、调用转换、返回结果） |
| `index.html` | 网页界面（右选文件 / 左看结果 / 页头选输出目录 / 下转换按钮） |
| `word2md.py` | 核心转换引擎（也可命令行调用） |
| `requirements.txt` | Python 依赖清单（`pip install -r requirements.txt`） |
| `README.md` | 本说明 |

## 快速开始

> 首次使用请先完成下方「环境要求与安装」一节（安装 Python 和依赖）。

1. 双击 `word2md.bat`，会自动打开浏览器页面；
2. 在页面**右侧**拖拽或点击选择 Word 文件（可多选，支持 `.doc` / `.docx` / `.rtf`）；
3. （可选）在页面右上角粘贴路径点「应用」，或点「浏览…」弹窗选择输出目录，不选则使用默认目录；
4. 点击下方「**开始转换**」按钮；
5. 页面**左侧**逐条显示每个文件的转换结果（成功 ✓ / 失败 ✗ 及原因）；
6. 点击右上角「打开输出文件夹」即可查看生成的 `.md`。

## 输出位置

默认输出到当前用户「下载」文件夹下的 `word2md_output\` 子目录（例如 `C:\Users\你的用户名\Downloads\word2md_output\`）。

也可以在页面右上角直接粘贴路径（点「应用」）或点「浏览…」弹窗选择任意输出目录。文档中的图片会导出到输出目录下的 `xxx_files/` 文件夹。

## 命令行用法（可选）

`word2md.py` 也可脱离网页直接命令行批量转换：

```bash
python word2md.py 文件1.docx 文件2.doc            # 转换指定文件
python word2md.py --dir 文件夹                     # 转换文件夹内所有 Word 文件
python word2md.py --dir 文件夹 --out 输出目录 -r   # 递归 + 指定输出目录
```

## 环境要求与安装

本工具依赖以下环境（换到新机器时需自行安装）：

| 依赖 | 用途 | 说明 |
| --- | --- | --- |
| Windows + Microsoft Word | 转换引擎 | **必需**（脚本通过 Word COM 接口转换文档） |
| Python 3.8+ | 运行环境 | 安装时勾选「Add python.exe to PATH」 |
| `pywin32` | 驱动 MS Word | 见下方安装命令 |
| `markdownify` | HTML → Markdown | 见下方安装命令 |
| `flask` | 本地 Web 后端 | 见下方安装命令 |

**安装步骤：**

1. 从 https://www.python.org/downloads/ 安装 Python 3，勾选「Add python.exe to PATH」；
2. 在本目录打开命令行，安装依赖：

```bash
pip install -r requirements.txt
```

3. 确认电脑已安装 Microsoft Word（未安装则无法转换）。

## 工作原理

1. 双击启动器 → 本地 Flask 服务启动，并自动打开浏览器页面；
2. 在页面选择文件后，浏览器把文件上传到本地服务；
3. 服务端通过 Word COM 自动化接口（`pywin32`）以隐藏方式打开文档，另存为「筛选过的 HTML」；
4. 用 `markdownify` 把 HTML 转成 Markdown，自动识别中文编码并导出图片；
5. 结果回传到页面左侧展示。

> 之所以用 Word 而不是 pandoc / LibreOffice：本机已安装 MS Word，Word 对 `.doc` 老格式和 `.docx` 的解析最忠实、最稳定。

## 支持的内容

- 标题（H1–H6）
- 粗体、斜体（下划线、删除线等 Word 特有格式会转为普通文本）
- 有序 / 无序列表
- 表格
- 图片（导出到 `xxx_files/` 文件夹，Markdown 中以相对路径引用）
- 超链接

## 常见问题

**Q：双击后没有自动打开浏览器？**
A：本地服务通常仍在运行。重新双击一次 `word2md.bat` 即可。

**Q：转换时提示「无法启动 Word」？**
A：说明本机未安装 Microsoft Word，或 Word 未激活/正被占用。请确认能正常打开 Word 后再试。

**Q：中文字符出现乱码？**
A：正常情况下脚本会自动识别编码。若个别文件仍乱码，请用 Word 打开该文件另存一次后再转。

**Q：图片在哪里？**
A：转换后与 `.md` 同目录会出现 `xxx_files/` 文件夹，图片都在里面。

**Q：转换大文件很慢？**
A：转换需启动一次 Word 并逐个处理，大文件或大量文件需要数秒到数十秒，属正常现象，请耐心等待按钮恢复。

**Q：如何退出工具？**
A：点击页面右上角「退出」即可关闭本地服务。

## 注意事项

- 转换过程会临时启动 Word（隐藏窗口），请勿在转换时手动关闭 Word。
- 输出 `.md` 若与已有同名文件冲突，会被覆盖。
- 本工具面向「内容转写」，不保证 Word 中的复杂排版（文本框、艺术字、批注、复杂分栏）100% 还原。
